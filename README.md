# Adidas-US-Interactive-Sales-Analysis

## Project Overview

This project focuses on analyzing Adidas US sales data to uncover insights related to revenue, product performance, regional trends, and sales channels. The analysis helps understand how Adidas products perform across different regions and retailers in the United States.

The project uses Excel-based interactive analysis including pivot tables, charts, and dashboards to support data-driven decision-making.

## Objectives

- Analyze total sales and profit trends
- Identify top-performing products and regions
- Compare sales across retailers and sales methods
- Understand monthly and yearly sales patterns
- Build an interactive dashboard for business insights

## Key Insights

- Certain regions contribute significantly higher revenue
- Specific product categories dominate total sales
- Online sales show strong growth compared to offline
- Seasonal trends impact monthly sales performance

## Conclusion

This project demonstrates practical data analysis and dashboarding skills using Excel. It highlights the ability to transform raw sales data into meaningful business insights through interactive visualizations.
